# Toman Bike Shop-Dashboard


## Problem Statement

This dashboard empowers the bike shop to make informed decisions about pricing strategies for the next year by providing actionable insights into past performance and seasonal trends.


### Steps followed 

- Step 1 : Load data into SSMS, dataset is in csv form.
- Step 2 : Write query to join the dataset for the year 2021, 2022 and Cost dataset.
- Step 3 : Calculate the revenue and profit and add the two columns in the dataset.
- Step 4 : Load data into PowerBI Desktop from SSMS.


# Insights

A single page report was created on Power BI Desktop 

Following inferences can be drawn from the dashboard;

#### Total Number of Customers = 3M
#### Total Revenue = $15M
#### Total Profit = $10.45M

Increasing the price by 25% from 2021 significantly boosted revenue, with the number of riders doubling. A further 10-15% price increase could generate additional revenue; however, detailed market research is necessary to account for external factors and ensure sustained customer satisfaction.
